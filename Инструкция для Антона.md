# Инструкция для Антона

Как забрать из репозитория и поставить в Proteus два листа релиза:
«Мониторинг рабочей активности» и «Структура HQ». Код в `main`,
коммит `0f0c26e`. Прежняя версия осталась в истории как `b4fbe81`.

## 1. Забрать актуальный `main`

```
git checkout main
git pull origin main
```

Рабочие файлы: `activity.sql`, `activity.chart.js`, `hq-portrait.data.sql`,
`hq-portrait.chart.js`. Что и почему изменилось — в `README.md`.

## 2. Лист активности: запрос

Заменить текст запроса в Proteus на содержимое `activity.sql` целиком
и выполнить. Проверить в выдаче:

- есть колонки `row_kind` и `flag_last_week`, в `row_kind` значения `month` и `week`;
- в строках `week` поле `date_structure` приходит датой понедельника;
- в строках `week` ровно у одной недели `flag_last_week = 1`, у предыдущей `= 2`.

Если неделя в витрине размечена не как понедельник–воскресенье, во второй
ветке запроса вместо `dateTrunc('week', calendar_dt)` подставить колонку
недели витрины. Иначе последняя точка спарклайна и число «Доля» в таблице
посчитаются по разным множествам сотрудников.

## 3. Лист активности: график

Заменить скрипт графика на `activity.chart.js` целиком, включая
присваивание `option` в конце файла. Частично копировать нельзя: файл
собран из семи блоков в фиксированном порядке.

Что должно быть видно после перерисовки:

- в шапке панели «Состав по категориям» переключатель «Месяцы / Недели»;
- в таблице спарклайны рядом с «Долей» в блоках недоработки и переработки;
- последняя точка спарклайна совпадает с числом рядом;
- клик по строке таблицы даёт полосу «Срез: Команда: …» сверху, `Escape` её снимает;
- в консоли браузера нет ошибок.

Если переключателя и спарклайнов нет, скрипт не увидел строк `week`.
Это штатное поведение на старой выдаче: значит, шаг 2 не применился.

## 4. Лист «Структура HQ»

Заменить скрипт на `hq-portrait.chart.js` целиком. Запрос
`hq-portrait.data.sql` не менялся, трогать не нужно.

Проверить: четыре вкладки переключаются, клик по строке даёт срез,
`Escape` снимает срезы, полноэкранный конструктор открывается
и закрывается, подсказка на воронке при активном срезе показывает строку
«Фильтры: …» с переносом.

## 5. Сверить оба листа рядом

Открыть оба листа и убедиться, что заголовки панелей, шапки таблиц,
вкладки и чипы срезов выглядят одинаково. Полный список согласованных
значений — в `README.md`, раздел «Общий словарь двух листов». Там же
перечислено, что изменилось в каждом файле. Если какое-то решение
не устраивает, откатывать его точечно по этому списку, а не файл целиком.

## 6. Откат

Прежние версии — в коммите `b4fbe81`:

```
git show b4fbe81:activity.chart.js
git show b4fbe81:activity.sql
git show b4fbe81:hq-portrait.chart.js
```

Новый скрипт активности работает и со старым запросом, поэтому откатывать
можно по одному файлу.
